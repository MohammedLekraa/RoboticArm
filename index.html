01 // PROJECT BACKGROUND

From human movement
to robotic actuation.

The objective

The project explores the design of a low-cost robotic system capable of reproducing hand and wrist movements through a sensorized glove.

The main challenge was not only to capture movement, but to integrate sensing, processing, communication, mechanical actuation and power electronics into a functional system.

ENGINEERING APPROACH

A complete hardware-software system in which physical movement is measured, processed and translated into mechanical action in real time.

02 // SYSTEM ARCHITECTURE

How the system works.

The system is divided into sensing, processing, communication and actuation stages.

01

Motion acquisition

Flex sensors capture finger bending, while the MPU6050 measures wrist orientation and angular movement.

02

Embedded processing

The microcontroller reads sensor signals, applies calibration and processes the measurements.

03

Wireless transmission

Processed movement data is transmitted between the glove and the robotic arm using Bluetooth.

04

Mechanical actuation

Servo motors control the robotic hand and forearm, translating the received commands into movement.

03 // HARDWARE DESIGN

Electronics and components.

INPUT SYSTEM

Sensorized glove

Five flex sensors measure finger bending. The MPU6050 provides inertial measurements for wrist movement.

CONTROL SYSTEM

Microcontrollers and electronics

ESP32-based controllers acquire, process and exchange data while managing the interaction with the actuators.

OUTPUT SYSTEM

Servo-driven robotic arm

Servo motors pull tendon-like strings to produce finger movements in the 3D-printed hand.

Design consideration

Power distribution and control-signal integrity were important challenges during integration, particularly when multiple servos operated simultaneously.

04 // FIRMWARE DEVELOPMENT

Turning sensor data
into movement.

Sensor acquisition and processing

The firmware reads analog signals from the flex sensors and inertial data from the MPU6050. Calibration and filtering are used to obtain measurements suitable for controlling the robotic system.

The processed values are mapped to actuator commands, allowing the robotic hand to reproduce the movements detected by the glove.

05 // ENGINEERING CHALLENGES

Building a system
that works as one.

01

Power stability

Simultaneous servo operation introduced power disturbances that affected system stability. This highlighted the importance of separating power and control considerations.

02

IMU drift and calibration

Inertial measurements required calibration and filtering to reduce drift and improve the consistency of wrist-angle estimation.

03

Mechanical integration

The interaction between printed parts, tendons and servos required iterative adjustments to obtain reliable movement.

04

System integration

Individual components had to operate together reliably, requiring repeated testing across sensing, firmware, communication and actuation.

06 // TESTING AND RESULTS

From prototype
to integrated system.

Outcome

The project resulted in an integrated prototype combining a sensorized glove, embedded controllers, wireless communication and a servo-driven robotic arm.

The development process provided practical experience in hardware-software integration, sensor calibration, electronics debugging and iterative prototyping.

KEY TAKEAWAY

A successful embedded system depends not only on individual components, but on how sensing, processing, power, communication and actuation interact as a whole.
